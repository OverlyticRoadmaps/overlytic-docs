---
title: 'Azure DevOps integration'
description: 'Connect Azure DevOps to sync work items and sprints with your roadmap.'
---

The Azure DevOps integration connects your ADO organisation to Overlytic, allowing work items and sprint progress to flow into roadmap bars automatically. This keeps effort and progress data current without requiring PMs to update Overlytic manually.

Connect ADO from **Workspace settings → Integrations** using your organisation URL and a personal access token with read permissions. The token is stored securely by Overlytic's backend.

Map ADO work items to roadmap bars from the bar detail panel. Progress is pulled from the linked work item's completion percentage. Sprint data can be used to validate roadmap timeline estimates against actual team capacity.
