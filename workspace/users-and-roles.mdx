---
title: 'Users and roles'
description: 'How workspace roles work and what each one can do.'
---

Every user in an Overlytic workspace is assigned one of three roles: **Viewer**, **Editor**, or **Admin**. Roles control what a user can read, create, and modify across the workspace.

Viewers can see all roadmaps, reports, and heatmaps but cannot make changes. Editors can create and edit roadmap content, log time, and manage ideas. Admins have full control including user management, workspace settings, and integration configuration.

Invite new users from **Workspace settings → Members**. Roles can be changed at any time by an Admin, and seat counts update automatically when you add or remove Editors and Admins.
