---
title: 'Dependencies heatmap'
description: 'See which items are blocked and trace the dependency chain to the root cause.'
---

The Dependencies heatmap lists all roadmap items that have at least one dependency, showing whether each item is blocked, clear, or a blocker for something else. Risk propagates through the chain — if a blocker is at high delivery risk, dependent items are flagged too.

Each row shows the item name, its dependency status, and the item it is waiting on. Clicking a dependency row expands the chain so you can trace blocks back to the root cause without navigating to individual roadmaps.

Use this view before planning sessions to identify which blocks need to be resolved before downstream work can continue.
