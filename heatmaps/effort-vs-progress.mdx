---
title: 'Effort vs progress'
description: 'Find items that are consuming resource but not making proportional progress.'
---

The Effort vs Progress heatmap plots every roadmap item on a quadrant: effort logged on the horizontal axis, progress made on the vertical axis. Items in the high-effort, low-progress quadrant are burning resource without results — these are your problem items.

The quadrant is calculated from logged time entries (effort) and the progress percentage set on each bar. Both inputs need to be reasonably up to date for the chart to be meaningful.

Use this view to identify items that need a conversation: either scope should be cut, more resource should be assigned, or the progress estimate needs to be revised.
