# Overlytic Docs

Documentation for [Overlytic](https://overlytic.com) — the roadmap and portfolio management tool for project managers and leadership.

Built with [Mintlify](https://mintlify.com).

## Contributing

Pages live in topic folders as `.mdx` files. Edit any file and push — Mintlify deploys automatically.

## Local preview

Install the Mintlify CLI and run:

```bash
npm i -g mintlify
mintlify dev
```
